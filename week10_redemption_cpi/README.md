# Модуль 10. Погашение квитанций и вывод активов через CPI (`redeem_liquidity`)

Реализация вывода средств из резерва с использованием двух последовательных CPI-вызовов в SPL Token Program: сжигание квитанций (`token::burn`, подписант — участник) и перевод базовых активов (`token::transfer`, подписант — PDA `ReservePool` через `CpiContext::new_with_signer`).

## Дополнения модуля

- Удержание комиссии выхода (`fee_bps` до 500 bps): удержанная часть остается в `reserve_account` и `managed_assets`, увеличивая обеспеченность квитанций оставшихся участников.
- Механизм аварийной паузы `set_pool_pause(paused)` блокирует новые депозиты, позволяя участникам беспрепятственно погашать свои квитанции.
