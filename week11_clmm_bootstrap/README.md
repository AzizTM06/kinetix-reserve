# Модуль 11. Инициализация пула концентрированной ликвидности (Raydium CLMM)

Выпуск торговой пары SPL-токенов (`KTX-A` и `KTX-B`, по 6 десятичных знаков), каноническая сортировка адресов (`mint_0 < mint_1`) и расчет ценовых параметров для пула Raydium CLMM в сети Devnet (`devi51mZmdwUJGU9hjN27vEz64Gps7uUefqxg27EAtH`).

## Параметры пула

- `tick_spacing = 60` (тарифный уровень `0.25%`–`0.30%`), рабочий диапазон тиков `[-600, +600]`.
- Начальная цена `P(0) = 1.0`, представление с фиксированной точкой `Q64.64`: `sqrt_price_x64 = 2^64 = 18446744073709551616`.
- Границы цены по формуле `P(i) = 1.0001^i`: нижняя `P(-600) ≈ 0.9418`, верхняя `P(+600) ≈ 1.0618`.

cd week11_clmm_bootstrap
