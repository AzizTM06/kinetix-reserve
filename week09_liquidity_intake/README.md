# Модуль 9. Прием ликвидности и выпуск квитанций (`contribute_liquidity`)

Реализация инструкции внесения базовых токенов в `reserve_account` и пропорциональной чеканки квитанционных токенов (`receipt_mint`) через CPI в SPL Token Program.

## Формула расчета квитанций

Для защиты от инфляционных атак на пустой или малонаполненный пул используется виртуальное смещение `VIRTUAL_OFFSET = 1000` в расширенной целочисленной арифметике `u128`:

`receipts = floor(amount * (issued_receipts + 1000) / (managed_assets + 1000))`

При пустом пуле формула сохраняет точное соотношение `1:1`, а при накоплении комиссий в `managed_assets` курс квитанции монотонно растет, исключая размытие доли ранних участников.
